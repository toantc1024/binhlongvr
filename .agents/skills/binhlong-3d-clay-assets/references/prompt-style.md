# Bình Long VR 3D Clay Icon Prompt Style Guide

Use these rules when writing or generating prompts for Bình Long VR 3D clay assets.

## Palette

Default green-based palette:
- Emerald Green: `#059669`
- Forest Green: `#047857`
- Mint / Soft Sage: `#10B981` / `#A7F3D0`
- Historical Bronze / Warm Gold: `#F59E0B` / `#D97706`
- Dark Navy / Slate: `rgb(0, 71, 118)` / `#1E293B`
- Warm Porcelain White: `#FFFFFF`

## Material and Texture
- Soft molded clay with thick rounded edges.
- Tactile inflatable look with smooth generous bevels.
- Satin-matte finish with soft specular highlights.
- Multi-layer interlocking parts.
- Isolated on clean white background, easily masked for transparent UI usage.
