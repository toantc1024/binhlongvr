# Bản Đồ Số Du Lịch Thực Tế Ảo Phường Bình Long (Bình Long VR) 🌟

> Nền tảng số hóa di tích lịch sử và văn hóa Phường Bình Long, Thành phố Đồng Nai trên không gian thực tế ảo 360°.

---

## 🏛️ Đơn Vị Quản Lý & Thực Hiện
- **UBND Phường Bình Long, Thành phố Đồng Nai**
- **Đoàn Trường Đại học Sư phạm Kỹ thuật TP. HCM (HCMUTE)**

---

## 🚀 Tính Năng Nổi Bật

- **Thực tế ảo 360° tương tác cao (VR Tour)**: Tham quan toàn cảnh chân thực các di tích lịch sử, âm thanh thuyết minh sống động theo từng điểm nhìn.
- **Bản đồ tương tác di tích số**: Định vị địa lý, xem thông tin tóm tắt, chỉ đường và mở trực tiếp tour VR tại từng di tích.
- **Hệ thống AI Chatbot hướng dẫn viên số**: Trả lời câu hỏi lịch sử, giải đáp thông tin di tích Bình Long nhanh chóng, chính xác.
- **Giao diện hiện đại & thân thiện**: Tông màu xanh lục mầm non tràn đầy sức trẻ kết hợp biểu tượng 3D Clay nghệ thuật.

---

## 📍 Các Điểm Di Tích Tiêu Biểu

1. **Di tích Lịch sử Quốc gia Mộ 3.000 người An Lộc**  
   Nơi ghi dấu sự hy sinh anh dũng của đồng bào và chiến sĩ trong cuộc chiến đấu bảo vệ quê hương năm 1972.
2. **Di tích Lịch sử Dinh Tỉnh Trưởng Bình Long**  
   Di tích Nhà và Đường hầm An Lộc với hệ thống lô cốt, công sự ngầm kiên cố.
3. **Di tích Lịch sử Mộ tập thể Lực lượng vũ trang An ninh An Lộc (Mộ 7 Người)**  
   Dấu tích lịch sử kiên cường thời kỳ kháng chiến cứu nước.
4. **Di tích Lịch sử - Văn hóa Chùa Hưng Lập Tự**  
   Ngôi chùa thanh tịnh gắn liền với Phòng thuốc Nam Phước thiện khám chữa bệnh miễn phí cho nhân dân.
5. **Di tích Lịch sử Ngã Năm Bình Long**  
   Giao lộ huyết mạch lịch sử kết nối các tuyến đường trọng điểm của Bình Long.

## 🛠️ Công Nghệ Phát Triển

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, MagicUI
- **VR Engine**: 3DVista Player & WebGL / WebAssembly
- **Bản đồ**: MapLibre GL / OpenStreetMap
- **Backend / Database**: Supabase

---

## 💻 Cài Đặt & Chạy Thử Nghiệm

```bash
# Clone repository
git clone https://github.com/toantc1024/binhlongvr.git
cd binhlongvr/frontend

# Cài đặt dependencies
pnpm install

# Chạy môi trường development
pnpm run dev
```

Truy cập ứng dụng tại `http://localhost:5173`.
